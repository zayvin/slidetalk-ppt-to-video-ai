# 如何把 PowerPoint 簡報轉成有旁白的教學影片？

假設你要替圖書館的新進志工做一支教學影片，說明收到預約書後如何通知讀者。簡報裡有三張操作截圖，最容易漏講的往往是按下按鈕後，畫面應該出現什麼。把這個判斷標準寫進旁白，志工就能邊看邊練。

## 範例：把操作步驟改寫成旁白

| 投影片 | 建議畫面 | 旁白試寫 |
| --- | --- | --- |
| 找到預約單 | 裁切到書名與取書分館兩欄 | 「先核對書名，再看取書分館。同一本書可能有好幾筆預約。」 |
| 發出通知 | 游標停在「通知讀者」按鈕旁 | 「確認分館相符後，再按『通知讀者』。」 |
| 確認完成 | 放大「已通知」狀態 | 「看到『已通知』才算完成。如果仍顯示『待通知』，先查看紀錄，以免重複寄送。」 |

這是虛構的教學介面。實作時用測試帳號截圖，把按鈕名稱換成讀者真正會看到的文字。

## 在 Mac、iPad 或 iPhone 製作影片

1. 先將投影片排成「操作前、操作中、操作後」。每張只保留一個要找的欄位。若原檔是 Keynote，可先輸出 PDF，讓字型與截圖維持原來的位置。
2. 在 SlideTalk 匯入 PPTX 或 PDF。請它為第一次值班的志工寫稿，每頁用一句話說明該做什麼，再用一句話說明如何確認成功。
3. 逐頁核對介面上的用詞，再試聽一頁旁白。念到按鈕名稱之前，畫面就應該已經顯示按鈕。
4. 匯出後，把影片放到手機上實際看一次。如果字幕蓋住底部的狀態欄，將截圖往上移並重新匯出該頁的畫面。最後請一位沒看過簡報的人照著操作。
