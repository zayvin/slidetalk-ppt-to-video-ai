# Transformer un PowerPoint en vidéo avec voix off et sous-titres

Pour une formation, choisissez d’abord un geste que la personne devra savoir refaire. Si la diapositive contient une capture d’écran, le commentaire doit indiquer où regarder et comment vérifier que l’action a réussi.

## Préparer une capsule sur Mac, iPhone ou iPad

1. Importez votre fichier `.pptx` dans SlideTalk. Si un schéma complexe se décale, exportez la présentation en PDF depuis son application d’origine, puis importez le PDF.
2. Précisez le public et l’action attendue. Relisez le texte proposé pour chaque diapositive. Remplacez « cliquez ici » par le nom visible du bouton.
3. Vérifiez qu’une voix est proposée pour la langue de votre formation. Écoutez une phrase avec cette voix, de préférence une phrase qui contient un sigle ou un nom de produit.
4. Exportez la vidéo, puis lisez-la sur un téléphone. Vérifiez que les sous-titres laissent visibles le bouton et le message de confirmation.

## Exemple de voix off pour un tutoriel

Imaginons un écran avec un bouton « Envoyer » et, sur la diapositive suivante, la mention « Demande reçue ».

> Quand le formulaire est rempli, choisissez « Envoyer », en bas à droite. Le message « Demande reçue » confirme que votre dossier a bien été transmis.

Faites apparaître la deuxième capture au moment où la voix annonce le message. Pour tester le montage, arrêtez la vidéo juste après « Envoyer » et vérifiez que le bouton est encore à l’écran. La personne doit avoir le temps de le repérer.
