# PPT 怎么转成带配音和字幕的视频？用一页图表做微课

一页作业讲评 PPT 上有两根柱子。老师现场讲时会问学生“进步了多少”，但把图表原样转成视频，这个问题就消失了。可以先为这一页写好提问、留白和答案，再给整套课件配音。下面用一组虚构的课堂数据试做。

## 把一页统计图写成三句讲解词

| 画面 | 讲解词 | 剪辑时看什么 |
| --- | --- | --- |
| 标出第一次测验的 60% | “第一次测验，每一百人中有六十人答对。” | 先让观众看清纵轴和单位。 |
| 出现第二次的 75% | “再看第二次。你会怎样描述这次进步？” | 问完留出短暂停顿，再揭晓答案。 |
| 两根柱子同时出现 | “答对率从百分之六十升到百分之七十五，提高了十五个百分点。” | 字幕里的“百分点”要完整显示。 |

这里也可以说“相对提高了 25%”，因为 15 除以 60 等于 0.25。如果学生正在学百分点，视频里只讲第一个答案，把第二种算法留作练习。

## 在 Mac、iPhone 或 iPad 上制作

1. **准备画面。** 如果原 PPT 靠点击动画逐步揭晓答案，把“提问”和“揭晓”做成两页。复杂图表先在 PowerPoint 中导出为 PDF，查看柱高、单位和图例是否完整。
2. **导入并逐页改稿。** 在 SlideTalk 导入 PPTX 或 PDF。给 AI 的提示可以写成“面向初中生，每页只解释一个数字。先提问，下一页再给答案”。拿原图逐个核对数字。
3. **先试听一道题。** 选择合适的声音，听完整段。若把“75%”念得生硬，可以在讲解稿里写“百分之七十五”，图中保留 75%。
4. **导出后用手机验收。** 先静音看一遍，检查字幕有没有遮住横轴。再只听声音，判断能不能听出题目和答案之间的停顿。

手头没有合适的 PPT，可以从[图表试做项目（含示例素材）](../../examples/chart-lesson/README.md)开始。需要和同事分工改稿时，复制这份[逐页分镜表 CSV](../../templates/storyboard-zh-CN.csv)。也可以直接套用[微课、演示与财报的中文讲稿提示词](../../templates/voiceover-prompts.md)。
