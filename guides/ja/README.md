# PowerPointをナレーション付きの動画にする方法

研修のスライドを動画にするなら、まず一枚だけ音声を付けてみましょう。会場では講師が指さしていた箇所も、動画では「こちらです」だけでは伝わりません。画面に書かれた言葉を手がかりに、見る場所と判断のしかたを伝えます。

## 例：架空の出張精算画面を説明する

元のスライドには「領収書を添付」「申請」の二行だけが載っています。動画用には、次のように操作の前後を分けます。

| 画面 | 読み上げ原稿 |
| --- | --- |
| 添付欄とファイル名 | 「領収書を選ぶと、添付欄にファイル名が表示されます。日付を見て、今回の出張のものか確かめましょう。」 |
| 申請後の一覧 | 「申請ボタンを押したら一覧に戻ります。状態が『申請済み』に変われば、ここで作業は完了です。」 |

二枚目の画面は、ボタンを押した瞬間に切り替えます。完了状態を読める時間を残すと、受講者は自分の画面と見比べられます。

## Mac・iPhone・iPadで書き出す手順

1. PowerPointで操作前後のスクリーンショットを別々のスライドに置きます。吹き出しや特殊なフォントの位置を保ちたいときは、PDFにも書き出して見え方を比べます。
2. SlideTalkにPPTXまたはPDFを読み込み、新入社員向けの原稿を作ります。「ここ」「右のほう」は、実際の項目名に置き換えます。
3. 使いたい言語に合う音声があるか、短い一文で試聴します。「4月1日」や社内の略称は、聞き手が一度で聞き取れる読み方に直しましょう。
4. 動画を書き出し、スマートフォンで字幕とボタンの重なりを確認します。次に画面を伏せて音声だけを聞き、作業の終わりが分かるか試します。

練習用ファイルは[グラフ解説のサンプル](../../examples/chart-lesson/README.md)にあります。手元の資料から始める場合は[絵コンテ用CSV](../../templates/storyboard.csv)を使えます。
