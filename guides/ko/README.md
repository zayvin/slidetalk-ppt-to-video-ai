# PPT를 내레이션과 자막이 있는 동영상으로 만드는 방법

동아리 발표 자료로 실험 영상을 만든다고 해 봅시다. 발표장에서는 손으로 가리키며 “이쪽이 더 빨랐습니다”라고 말해도 됩니다. 동영상에서는 어떤 시료를 비교하는지, 무엇을 재었는지까지 들려줘야 그래프를 따라갈 수 있습니다.

## 한 장으로 연습하기 — 얼음이 녹는 시간

아래 수치는 대본 연습용으로 만든 예시입니다. 두 막대에 각각 ‘작은 조각 6분’, ‘큰 덩어리 10분’이라고 적혀 있습니다.

| 순서 | 보여 줄 부분 | 내레이션 예시 |
| --- | --- | --- |
| 질문 | 두 시료의 사진 | “무게가 같은 얼음을 잘게 나누면 녹는 시간이 달라질까요?” |
| 관찰 | 시간 축과 두 막대 | “이번 실험에서 작은 조각은 6분, 큰 덩어리는 10분 만에 모두 녹았습니다.” |
| 해석 | 두 값의 차이 | “이 조건에서는 잘게 나눈 쪽이 4분 빨랐습니다. 조건을 바꾸면 결과도 달라질 수 있습니다.” |

숫자를 모두 읽고 나서야 막대가 나타나는 구성이라면 슬라이드를 둘로 나누세요. 질문 화면에서 결과를 미리 보여 주지 않아도 됩니다.

## Mac, iPhone 또는 iPad에서 영상 만들기

1. PowerPoint에서 질문과 결과 화면을 준비합니다. 기본 애니메이션에 의존하는 부분은 별도 슬라이드로 만드세요. 그래프가 복잡하면 PDF로 내보내 모양을 먼저 확인합니다.
2. SlideTalk에 PPTX 또는 PDF를 가져옵니다. AI에 대상과 목표를 알려 주고, 생성된 대본을 원본과 대조합니다. 특히 ‘녹기 시작한 시간’과 ‘모두 녹은 시간’을 구분하세요.
3. 사용할 언어에 맞는 음성을 한 문장으로 시험해 봅니다. ‘6분’과 ‘10분’ 사이가 너무 짧아 구별하기 어렵다면 두 문장으로 나누어 들어 보세요.
4. 영상을 내보낸 뒤 작은 화면에서 자막이 단위 ‘분’을 가리지 않는지 확인합니다. 소리를 끈 채 보아도 어느 시료가 먼저 녹았는지 알 수 있어야 합니다.

다른 그래프로 연습하려면 [예제 자료](../../examples/chart-lesson/README.md)를 열어 보세요. 직접 구성하려면 [슬라이드별 스토리보드 CSV](../../templates/storyboard.csv)에 화면과 대본을 정리할 수 있습니다.
