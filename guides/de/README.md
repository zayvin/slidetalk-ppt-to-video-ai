# PowerPoint in ein Video mit Sprechertext und Untertiteln umwandeln

Bei einer vertonten Präsentation muss der Blick mit dem gesprochenen Satz Schritt halten können. Für eine Schulung oder einen Monatsbericht lohnt sich deshalb ein Test mit der Folie, auf der die meisten Zahlen stehen.

## Eine Folie auf Mac, iPhone oder iPad vertonen

1. Importiere die `.pptx`-Datei in SlideTalk. Sind Diagramme verschoben oder fehlen Beschriftungen, exportiere die Präsentation in PowerPoint als PDF und verwende diese Datei.
2. Gib an, wer das Video sehen wird und welche Frage die Folie beantwortet. Prüfe den generierten Sprechertext anhand der Achsen und Einheiten.
3. Prüfe, ob für die gewünschte Sprache eine Stimme verfügbar ist, und höre dir einen Satz an. Schreibe schwer verständliche Kürzel im Sprechertext aus. Auf der Folie kann die vertraute Kurzform stehen bleiben.
4. Exportiere das Video und kontrolliere auf dem Smartphone, ob die Untertitel Achsentitel oder Legende verdecken. Für separat zuschaltbare Untertitel steht auch eine SRT-Datei zur Verfügung.

## Beispiel für einen Monatsbericht

Auf einer Beispielfolie sinkt die Lieferzeit von 4,0 auf 3,2 Tage. „Die Lieferzeit ist gesunken“ lässt offen, ob das im Betrieb einen Unterschied macht. So lässt sich der Unterschied erklären.

> Im Mai dauerte eine Lieferung im Schnitt vier Tage, im Juni waren es drei Komma zwei. Damit kamen die Pakete im Durchschnitt fast einen Tag früher an.

Rechne die Differenz beim Gegenlesen kurz nach. 4,0 minus 3,2 ergibt 0,8 Tage. Die Folie belegt damit eine Veränderung. Eine Erklärung für die Ursache braucht zusätzliche Daten.
