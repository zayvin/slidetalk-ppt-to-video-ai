# PPTX or PDF? Choose the right input for a slide video

Pick the slide most likely to break and import that one first. Good candidates are a chart with small axis labels, a custom font or a diagram that reveals its answer one click at a time. Compare the import with the original in PowerPoint before preparing the rest of the deck.

| What the slide contains | Start with | What to inspect |
| --- | --- | --- |
| Simple text boxes, photos and shapes | PPTX | Look for text wrapping onto a new line, cropped images and labels that have shifted. |
| A chart, SmartArt or a gradient that carries meaning | PDF exported from the original deck | Check the legend, axis units and contrast. Zoom in on the smallest label. |
| An animation that reveals the answer | A separate slide for each meaningful state, then PPTX or PDF | Step through the pages in order. The answer should first appear when the narration gives it. |
| A legacy PowerPoint file or a Keynote deck | Open the original in its authoring app and export a PDF, or save a PPTX copy | Open the new file before import. Changing the filename extension does not convert it. |

## Preserve a chart reveal

Suppose a lesson asks viewers to predict which route is faster. The original slide adds a second bar on click. Duplicate that slide in the authoring app. On the first copy, remove the answer bar and its numeric label. On the second, keep both bars and the answer. Use the same axis limits and leave the bars in the same positions on both pages, so viewers can compare them without reorienting themselves.

Export both pages to a slide-only PDF. A PDF keeps each exported page as a still image of the layout when SlideTalk renders it. The sequence now works even when the source animation does not carry over. Use the first page for the question and the next for the reveal.

## Check the file you will actually use

- Compare the difficult page in the imported preview with the original at the same size. Look at the longest label and the smallest unit.
- Check the page count and order. If speaker notes or handout thumbnails appear **inside the page**, export slides rather than notes or handouts.
- Play one page on the intended device. A faithful PDF can still contain text too small for a phone. Enlarge the important part in the source and export again.
