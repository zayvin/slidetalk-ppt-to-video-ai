# Four prompts for writing a slide voiceover

Paste one brief alongside the relevant slide text when requesting a narration draft. Replace the bracketed fields with your actual audience, labels and values. Read the result against the slide before generating audio.

## 1. Teach a chart

> Explain this chart to [audience]. Start with the question it answers. Name the baseline and its units before comparing the two values. Use only numbers visible on the slide or in the supplied notes. If you need a missing denominator, ask for it. End with one sentence the viewer should remember.

**中文可直接使用**  
向[听众]解释这张图。先说它回答什么问题，再指出起点、终点和单位。只使用图或备注中给出的数字。缺少分母时请指出来。结尾用一句话讲清楚观众应该记住什么。

**Check the draft.** If the graph goes from 20% to 30%, have the speaker say “ten percentage points” for the difference. Add “fifty percent relative to the starting rate” only if the comparison serves the lesson.

## 2. Demonstrate a product

> Talk a new user through [one task]. For each slide, name one visible control exactly as printed, describe the action, and say what confirms it worked. Use the supplied screenshots as the source for button labels. Keep silent about controls you cannot see.

**中文可直接使用**  
带新用户完成[一个具体操作]。每页只讲一个动作，按截图原样说出按钮名称，再告诉观众成功后会看到什么。请把截图中看不清的文字列为待确认项。

**Check the draft.** Replace “continue to the next screen” with a visible signal, such as “the preview appears beside the file name,” after checking the screenshot.

## 3. Turn a lecture slide into a microlecture

> Teach [one concept] to someone who already knows [prerequisite]. Open with a question. Use the diagram to explain the answer in two steps. Mark one pause in the production notes. Write the words to be spoken separately from those notes.

**中文可直接使用**  
给已经了解[前置知识]的学生讲[一个概念]。先问一个能从本页找到答案的问题，再结合图示分两步解释。把需要停顿的位置写在制作备注中，另起一段给出可以直接配音的讲稿。

**Check the draft.** Read only the spoken words into the voice generator. Put the pause and the planned highlight in the storyboard.

## 4. Explain a business result

> Compare [this period] with [comparison period]. Give the metric, unit and dates. Distinguish a change in the reported number from an explanation for the change. If the supplied material does not state a cause, leave it open. Finish with the specific decision this slide informs.

**中文可直接使用**  
比较[本期]与[对比期]。讲清指标、单位、日期，再说明变化幅度。如果材料没有解释变化原因，保留这个问题。最后说明这页信息可以帮助观众做什么判断。

**Check the draft.** Change “the campaign caused the increase” to “signups rose during the campaign” if the slide establishes timing alone.
